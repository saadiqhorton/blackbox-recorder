GStack Roles by GSD Phase

Phase Discussion (GSD /gsd-discuss-phase)

Activates GStack roles:

• /plan-ceo-review → reframes product vision
• /plan-eng-review → locks architecture

Phase Planning (GSD /gsd-plan-phase)

Activates GStack roles:

• /plan-design-review → validates design decisions
• /cso → security review for the phase scope

Phase Execution (GSD /gsd-execute-phase)

Superpowers skills take over:

• test-driven-development → write tests first
• subagent-driven-development → parallel task execution
• code-review → verify before completion

Phase Close

• /ship → sync, test, push, PR
• /qa → browser-based verification if UI work
